# Create an audiobook from an attachment

Use a Linux cloud workspace with Python 3.11 and access to GitHub, PyPI, and Hugging Face. GitHub Codespaces runs dependency setup automatically.

1. Put the attachment in `inputs/`. Timeless Narrations can read PDF text, EPUB, DOCX, TXT, Markdown, and chaptered JSON. Check for scanned or unreadable pages. Recover those with OCR in the workspace before rendering and check the recovered text.
2. Use the file directly for single-voice narration. For dialogue or multiple authors, analyze the entire manuscript for speaking roles. Use dialogue tags, scene context, and author-labeled passages as evidence. Consolidate aliases, retain separate identities for distinct speakers, keep the original wording and order, and write `inputs/book.md` with named turns and `inputs/book.cast.json` using the README’s format. Include a short role description and any supported age or gender details. Use one canonical profile per person throughout. For coauthors, use separate speaker IDs even when they share the same age or gender. Keep unattributed prose with the narrator. If a speaker is ambiguous, let the narrator read the passage and mention that in your handoff.
3. If the user gives no settings, use the deep narrator, 90% pace, the default chapter pauses, and all three formats. Run `bash scripts/render-book.sh inputs/book.pdf` with the correct file path. For a cast, append `--cast inputs/book.cast.json` to a prepared Markdown render. Use `--formats m4b`, `--pace 1.0`, or `--narrator warm-narrator` when requested.
4. Before rendering an attributed manuscript, add `--plan-only` to inspect the resolved cast. Check that every identified speaker has a unique voice ID and pitch combination, and that named coauthors have different base voices when available. Remove `--plan-only` for the full render.
5. Wait for the final JSON summary. Verify that the `outputs` paths exist and return each requested file through the workspace’s downloadable artifact feature. Read the `.cast-report.json` next to the audiobook. Give the user a short cast table with each speaker, role, voice ID, and pitch if adjusted. Report the pace multiplier, measured words per minute, chapter count, and runtime. Use the optional transcription check when source accuracy needs extra review.
6. To resume, run the same command in the same workspace. Keep the input and completed line cache. Keep the source document, cast, and audio in the private workspace. Commit only code and authorized public examples.
